## Objective

The objective of this lab was to configure and apply Group Policy settings to domain users within the `itlab.local` Active Directory environment. I configured policies for desktop wallpaper, Windows Firewall, and folder redirection to demonstrate centralized configuration management and consistent user settings across the domain.

## Implementation Steps

### Step 1: Configure Group Policy for Domain Users

Accessed Group Policy Management and configured Group Policy settings for domain users. This provided a centralized way to manage user and computer configurations rather than configuring each account or workstation individually.

**Screenshot 1:** Group Policy Management Console

### Step 2: Configure Desktop Wallpaper Policy

Configured a Group Policy setting to control desktop wallpaper for domain users. Centralized wallpaper configuration helps maintain a consistent desktop appearance across the managed environment.

**Screenshot 2:** Desktop Wallpaper Group Policy Setting

### Step 3: Configure Windows Firewall Policy

Configured Windows Firewall settings through Group Policy to manage firewall behavior centrally. Firewall policies help establish consistent security configurations for computers within the domain.

**Screenshot 3:** Windows Firewall Group Policy Configuration

### Step 4: Configure Folder Redirection

Configured Folder Redirection through Group Policy to redirect designated user folders to a specified network location. This feature can centralize user data storage and make supported folders accessible independently of the user's local workstation, depending on the configuration.
