<h1 align = "center">Azure Active Directory</h1>

<h3>Project Overview</h3>

<p>This project demonstrates the deployment, configuration, and management of an Active Directory domain environment in Microsoft Azure. The goal was to build a functional Windows domain infrastructure with core system administration and identity management tasks.</p>

<p>The project covers domain controller deployment, client domain joining, Active Directory object management, remote access configuration, delegated administration, Group Policy management, and file sharing with network drive mapping.</p>

<p>Through this lab, I managed domain users and computers, implemented access controls, applied centralized security policies, and configured shared resources in a centralized Windows environment.</p>
